REVITALIZZE HAIR THERAPY - PACOTE PARA VERCEL

Este pacote já contém o site estático completo e não precisa de instalação,
compilação ou dependências.

COMO PUBLICAR PELO SITE DA VERCEL

1. Extraia este arquivo ZIP.
2. Acesse https://vercel.com/new
3. Crie um novo projeto e envie a pasta extraída por um repositório Git,
   ou use a opção de implantação disponível na sua conta.
4. Caso a Vercel solicite configurações:
   - Framework Preset: Other
   - Build Command: deixe em branco
   - Output Directory: deixe em branco
   - Install Command: deixe em branco
5. Clique em Deploy.

O arquivo index.html deve permanecer na raiz da pasta junto com app.js,
services.js, styles.css, vercel.json e a pasta assets.
